# Poizon Order Bot

Телеграм-бот для приёма заявок на заказ вещей с Poizon. Пользователь заполняет
короткую форму (имя, товар, размер, контакт, комментарий), заявка сохраняется
в базу и сразу пересылается администратору в чат с кнопками «Принять» /
«Отклонить».

## Возможности

- Пошаговая форма заказа с проверкой введённых данных
- Хранение заявок в SQLite (`orders.db`)
- Мгновенное уведомление админа(ов) о новой заявке
- Кнопки принятия/отклонения заявки прямо в уведомлении
- Пользователь получает уведомление о статусе своей заявки
- Команда «Мои заказы» — история заявок пользователя

## Установка

1. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Получи токен бота у [@BotFather](https://t.me/BotFather):
   - `/newbot` → следуй инструкциям → скопируй токен

3. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot) —
   это будет ID администратора для получения заявок.

4. Настрой переменные окружения. Скопируй `.env.example` в `.env` и заполни:
   ```
   BOT_TOKEN=твой_токен_от_botfather
   ADMIN_IDS=123456789
   ```
   Если админов несколько, укажи их ID через запятую: `ADMIN_IDS=111,222`.

   Либо просто впиши значения напрямую в `config.py`.

5. Если используешь `.env`, установи `python-dotenv` и добавь в начало
   `bot.py`:
   ```python
   from dotenv import load_dotenv
   load_dotenv()
   ```
   (или экспортируй переменные окружения перед запуском вручную).

## Запуск

```bash
python bot.py
```

Бот запустится в режиме polling. Для продакшена рекомендуется:
- запускать через systemd / supervisor / Docker, чтобы бот перезапускался при сбоях
- перейти на webhook-режим при высокой нагрузке

## Как это работает для пользователя

1. `/start` — приветствие и главное меню
2. «🛒 Оформить заказ» — запускается форма:
   - Имя
   - Ссылка на товар (или описание, если ссылки нет)
   - Размер
   - Контакт (телефон / @username)
   - Комментарий (необязательно)
3. Подтверждение заявки → она сохраняется и уходит админу
4. «📦 Мои заказы» — список всех заявок пользователя со статусами

## Возможные доработки

- Оплата через ЮKassa / Тинькофф / крипто-эквайринг
- Расчёт стоимости с учётом курса юаня и доставки
- Парсинг ссылки Poizon для автоматического получения фото и цены товара
- Многоязычный интерфейс
- Веб-админка вместо кнопок в чате
